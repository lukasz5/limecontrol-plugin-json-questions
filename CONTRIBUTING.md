# Współpraca / Contributing

Otwórz zgłoszenie lub PR z opisem problemu, użytego motywu, wersji LS i wyniku testów. Dołącz jedynie przykłady z fikcyjnymi danymi. Uruchom polecenia testowe z README. Każdy PR przechodzi PHPStan, testy modelu i przeglądarki oraz testy rzeczywistej instalacji.

Open an issue or PR with the problem, theme, LS version and test results. Include only synthetic fixtures. Run the commands in the README. Every PR runs PHPStan, model and browser tests and clean-install integration tests.

Zmiany wnoszone do projektu są objęte GPL-2.0-or-later. Contributions are licensed under GPL-2.0-or-later.
