# Bezpieczeństwo / Security

Zgłoszenie dotyczące bezpieczeństwa wyślij prywatnie na [info@strefabadan.pl](mailto:info@strefabadan.pl). Podaj wersje wtyczki, LimeSurvey i PHP, wpływ problemu i kroki odtworzenia na fikcyjnej ankiecie. Do wiadomości dołącz wyłącznie dane syntetyczne.

Report security issues privately to [info@strefabadan.pl](mailto:info@strefabadan.pl). Include the plugin, LimeSurvey and PHP versions, impact and reproduction steps on a synthetic survey. Share only synthetic data.
